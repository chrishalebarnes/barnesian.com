There are a lot of webapps and 10 foot UI TV-friendly apps out there to get more “over the top” content to HTPC owners. It is a bit of a mess to try to find all of these ways of getting content. Using Windows Media Center, Google Chrome, and my own [Relaunch](https://www.barnesian.com/2011/05/relaunch-launcher-for-windows-media.html), I can use all of these 10 foot apps to get more content through my HTPC. You don’t necessarily have to use that combination, as any HTPC can run these if you have a way of launching a browser.

[Clicker.tv](http://tv.clicker.com/)– This is an aggregator app with sources from Amazon, iTunes, Netflix, Comcast, and Hulu.

{% include post_image.md name="ClickerTv.png" %}

~~[YouTube.com/xl](http://www.youtube.com/xl) – Plain and simple: 10 Foot UI for YouTube.~~ YouTubeXL has been discontinued.

{% include post_image.md name="YouTubeXL.png" %}

[YouTube.com/leanback](http://www.youtube.com/leanback) – Another one from YouTube that plays a lot of related videos in succession.

{% include post_image.md name="YoutubeLeanback.png" %}

[YouTube.com/tv](http://www.youtube.com/tv) – Yet another option from YouTube. This seems to be the best of the lot for the moment. You have to use their new [pairing procedure to login](http://thedigitallifestyle.com/w/index.php/2012/10/04/add-a-youtube-tv-icon-in-to-windows-media-center-plus-youtube-tv-setup/). You can also control it from a mobile device!

{% include post_image.md name="YoutubeTv.png" %}

[Hulu Desktop](http://www.hulu.com/labs/hulu-desktop) – While not strictly a web app, it is a 10 UI application that gets you access to Hulu’s catalogue.

{% include post_image.md name="HuluDesktop.png" %}

[Google TV Spotlight Apps](http://www.google.com/tv/spotlight-gallery.html) – This one is a meta app of sorts. It has [Crackle](http://www.crackle.com/gtv/), [adult swim](http://www.adultswim.com/leanback/) and [clicker.tv](http://tv.clicker.com/) links, among many others.

{% include post_image.md name="GoogleTV.png" %}

Those are all the HTPC-friendly content sources that I know of. If you have any more, leave a comment!
